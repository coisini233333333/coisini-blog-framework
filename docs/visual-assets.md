# 美术定制

保留浅米白与灰绿配色、圆角卡片和响应式布局。全站颜色与字体变量在 `src/styles/global.css` 顶部，暗色主题在相邻的主题选择器内。

- 内容包 `site.json` 的 `heroImage`、`heroImageAlt` 控制首页图与替代文本。
- `avatarImage` 控制右上角圆形头像与关于页头像；图片无需手工裁圆，CSS 自动居中裁切。
- 图片放在内容包 `public/images/`，使用 `/images/name.jpg` 引用。
- 文章 `cover` 可独立指定封面；没有封面时使用 `art` 对应的风景、粒子或界面 SVG。
- 内置 `landscape.svg` 与组件 SVG 可在代码中修改颜色、线条和图形。
- 字体使用本机字体栈，没有外部字体请求。

框架不附带个人头像、私人项目介绍或历史设计素材。复制内容包后可以替换任意图片；新资源请自行确认使用权限。`public/` 全部会复制到网站，即便页面没有引用它。
